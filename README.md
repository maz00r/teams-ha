# Teams na telefonie — dodatek Home Assistant

Microsoft Teams w przeglądarce działającej na serwerze HA, obsługiwany z panelu
dopasowanego do telefonu, z powiadomieniami push o nowych wiadomościach.

Instalacja: **Ustawienia → Dodatki → Sklep → ⋮ → Repozytoria** →
`https://github.com/maz00r/teams-ha`. Szczegóły: [teams_browser/README.md](teams_browser/README.md).

Testy: `python3 -m unittest -v test_notifier test_panel`
